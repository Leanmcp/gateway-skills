# The reference implementation

This skill is a generalization of a working system in the `tau2-bench` repo
(`path/to/tau2-bench`). When you want to see any
pattern here at full scale — with the domain-specific parts still attached —
read these files. They are the proof that the format survives contact with a
real research programme, not a design sketch.

## Map

## Details worth stealing verbatim

**Two run trees, one viewer.** Training writes `sim_runs/`, evaluation writes
`evals_run/`, and the viewers scan both. Separate trees keep a sweep from
burying your training history; one viewer keeps you from maintaining two.

**W&B in its own tree.** `wandb_runs/` is separate from the obs folders, so
W&B's local scratch files never pollute the run directories you grep.

**Retries are events, not silence.** `duplicate_tool_call_retry`,
`empty_output_retry`, `truncation_retry`, `context_overflow` — each is a
resample that changes the sampled distribution. Unlogged, they make a run
irreproducible in a way nobody notices.

**The user simulator is logged as a first-class speaker.** On a duplex benchmark
half the conversation is generated by another model; a trace with only the agent
side cannot explain why the agent said what it said.

**Auxiliary models get their own role.** The context-manager summarizer logs
under `role="ctxmgr"`, and the session counters deliberately *exclude* it — it
is machinery, not an orchestrator step, and counting it would corrupt the
`max_steps` and flood thresholds.

**Limit flags on the session list.** The turn count paints red when the episode
hit `max_steps`; the tool count paints red at the flood threshold. An episode
cut off by an artificial ceiling is a different failure from one that finished
and got it wrong.

**Expected vs actual tool calls.** The viewer builds the left column from the
transcript and the right from the task's ground-truth actions — no model
involved — and paints per-call verdicts inline: matched, right tool with wrong
arguments (with a field-level diff), or off-script. Reading the turn's reasoning
right where a wrong-argument call happened is the fastest route from "it failed"
to "here is why".

**The grader's justification, in the trace.** For LLM-judged rewards, the
per-check `met` flag and `justification` come from the episode artifact and are
shown in-session. The transcript alone never carries the reasoning behind the
score.

**Notes outlive runs.** One append-only `notes.jsonl` for the whole system,
addressed by run + session + `gseq`, with an "all notes everywhere" view. It
becomes the lab notebook, and it is the feature people underestimate.

## What this skill deliberately dropped

The generic version omits tau2-specific machinery — task tiers, DB-state checks,
curriculum filters, retrieval-variant chips, context-manager events. Those are
the *right* things to add back for a specific project, as synthetic items and
extra event kinds, without touching `obs.py`. See the "Extending the viewers"
section of [viewers.md](viewers.md).
